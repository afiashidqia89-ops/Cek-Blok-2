PetaTag PWA - cara pasang
1. Unggah SELURUH isi folder ini (termasuk folder lib/ dan icons/) ke hosting HTTPS
   (Netlify Drop, Cloudflare Pages, GitHub Pages).
2. Buka link-nya di Chrome Android SAAT ONLINE, tunggu 5-10 detik, lalu menu (titik tiga) > Instal aplikasi.
3. Setelah itu aplikasi, pustaka PDF, dan peta yang pernah diimpor tersimpan di HP dan jalan tanpa jaringan.
   Cek di menu Simpanan > tab Peta: semua baris harus bertanda centang.
Jika mengubah berkas, naikkan nama cache 'petatag-v4' di sw.js agar pengguna mendapat versi baru.
